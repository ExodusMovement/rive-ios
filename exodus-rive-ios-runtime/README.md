# @exodus/rive-ios-runtime

This package bundles the hardened **rive-ios runtime** for use via **npm**.  
It lives inside the [`rive-ios`](https://github.com/ExodusMovement/rive-ios) fork.

---

## 📦 Installation

```sh
yarn add @exodus/rive-ios-runtime
```

ios/Podfile

```podfile
pod 'RiveRuntime', :podspec => '../node_modules/@exodus/rive-ios-runtime/RiveRuntime.podspec'
```
